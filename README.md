# 💱 Конвертер валют / Currency Converter

*Красивый конвертер валют с актуальными курсами в реальном времени.*

## ✨ Возможности

- 🌍 **160+ валют** с флагами стран
- 🔄 **Актуальные курсы** в реальном времени (API: exchangerate-api.com)
- ⭐ **Избранные валюты** — сохраняются в браузере
- 🌐 **Два языка** — русский и английский
- 📱 **Адаптивный дизайн** — работает на всех устройствах
- 💾 **Сохранение настроек** — выбранные валюты не сбрасываются
- 🎨 **Современный UI** — glassmorphism, анимации, градиенты

## 📦 Технологии

- **React 18** — UI библиотека
- **TypeScript** — типизация
- **Vite** — сборщик
- **Tailwind CSS 4** — стили
- **ExchangeRate API** — курсы валют
